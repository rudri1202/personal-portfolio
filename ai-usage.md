# AI Usage Report

## 1. AI Tools Used
| Tool | How it was used |
|------|-----------------|
| **Claude Code** (Anthropic, Claude Opus 5.5), via the VS Code extension | Code generation, browser testing, documentation drafts and Git operations, all driven by my instructions |

## 2. How I Worked with AI
I used Claude Code as a coding assistant, and I directed the project throughout:

- **Requirements and content:** I gave it the assignment brief and my CV, and decided what the portfolio should and should not show.
- **Privacy decisions:** I chose to mention only "past internship experience" instead of listing companies, and to leave out my phone number, my current client's name and my photo.
- **Review and rejection:** I reviewed the generated UI and rejected output I didn't want, most notably a profile photo the AI added without asking.
- **Repository and submission:** I created the GitHub repository, chose how the commit history should look, and asked for the final submission package.

Most of the code itself was generated by the AI, and I have reported that openly below.

## 3. Tasks Where AI Helped
| Area | What the AI did |
|------|-----------------|
| Planning | Mapped the assignment requirements and my CV into page sections |
| HTML / CSS / JS | Generated the first versions of `index.html`, `css/style.css` and `js/script.js` |
| Content | Picked projects from my public GitHub repositories and wrote their descriptions |
| Testing | Wrote and ran a browser test script (Puppeteer + Microsoft Edge) for the full user flow |
| Documentation | Drafted `README.md`, this report and the POE Word document |
| Git | Made the commits, cleaned up the commit history and pushed to GitHub |

## 4. Representative Prompts
These are my actual requests, reworded for clarity:

1. *"Build a responsive personal portfolio with HTML, CSS and vanilla JavaScript that meets this assignment brief, using the details from my CV. Keep the design clean and simple enough that I can explain every part of it."*
2. *"Don't list my previous companies. Just say 'past internship experience'."*
3. *"Remove my photo from the landing page and from the screenshots."*
4. *"Clean up the commit messages and push the project to my GitHub repository."*
5. *"How does the contact form handle submissions? Where would the messages go?"*
6. *"Create a Word report with proof-of-execution screenshots and package the project for submission."*

## 5. Code Accepted, Modified or Rejected
| Decision | Item | Reason |

| ✅ Accepted | Semantic page structure, CSS variables for theming, Grid/Flexbox layouts | Met the requirements and are easy to explain |

| ✏️ Modified | About section: no company names, only "past internship experience" | My privacy preference |
| ✏️ Modified | Inline theme script moved from `<head>` into `script.js` | The brief requires separate HTML, CSS and JS files |
| ❌ Rejected | Profile photo the AI downloaded from my GitHub and added to the hero section | Added without asking; replaced with a CSS "RJ" initials badge |

## 6. Bugs or Incorrect Suggestions
- **Unrequested personal data:** the AI used my GitHub profile picture without asking. I caught this when I reviewed the UI and had it removed from the site, the screenshots and the Git history.
- **False alarm while testing:** an early dark-mode screenshot looked unreadable. It had been taken during the 0.3s colour transition, so it was not a real bug. A delayed screenshot confirmed dark mode is fine.
- **Contact form scope:** the form only simulates sending, which the brief allows ("a backend is not required"). It is listed under Known Limitations in the README.
